Dice

Provably fair dice roll

Paste the revealed server seed, your client seed, and the nonce from the fairness panel. The roll is a deterministic value from 00.00 to 100.00.

SHA-256(server seed)
Result digest

Algorithm: digest = SHA-256(client_seed:server_seed:nonce). Take the first 4 bytes as an unsigned 32-bit integer, then roll = ((uint32 * 10001) / 2^32) / 100. This is multiply/divide, not modulo, so the 10,001 outcomes stay unbiased.

Query params: client_seed, server_seed, nonce, hash.

Runs entirely in your browser. Same math as CasinoFairness.verifyDiceRoll.
